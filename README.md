# Exercício: conversão de AFN para AFD

Página interativa para treinar a conversão de um Autômato Finito Não Determinístico (AFN) em um Autômato Finito Determinístico (AFD) pelo método dos subconjuntos. Feita para a disciplina de Computabilidade e Complexidade de Algoritmos (Engenharia de Software, UDF).

## O que tem na página

1. **Tabela de transição do AFN:** já vem montada; é só preencher.
2. **Tabela de transição do AFD:** adicione uma linha para cada conjunto alcançável (ou liste os 8 subconjuntos e marque os inacessíveis). Marque o estado inicial e os finais.
3. **Renomear para S0, S1…:** cria uma coluna com nomes curtos para cada estado. O botão do olho volta para a tabela original.
4. **Perguntas:** total de subconjuntos, inacessíveis, estado morto e teste de cadeias.
5. **Diagrama do AFD:** monte o desenho sem desenhar: crie estados, arraste e ligue as transições clicando.

Cada passo tem correção automática com dicas, e o botão "Copiar minhas respostas" gera um texto para revisar depois. O que você digita fica salvo no seu navegador.

## Como usar

Abra a página publicada (GitHub Pages) ou baixe o `index.html` e abra no navegador. Não precisa instalar nada.
