Conversão de AFN para AFD

Exercício no mesmo estilo da aula, com outro autômato. As tabelas já estão prontas: é só preencher, adicionar linhas ou colunas e clicar em Corrigir.

O AFN do exercício

Estados
Q = {q0, q1, q2}
Alfabeto
Σ = {a, b}
Inicial
q0 (seta de entrada)
Final
F = {q2} (círculo duplo)

Não tem transição vazia (ε). Onde não sai seta com aquele símbolo, a transição vai para o conjunto vazio ∅.

Como fazer (resumo do método)
  1. Monte a tabela do AFN: para cada estado e cada símbolo, escreva o conjunto de destinos.
  2. O estado inicial do AFD é {q0}. Coloque ele na primeira linha.
  3. Para cada linha, a transição com um símbolo é a união dos destinos de cada estado que está no conjunto.
  4. Todo conjunto novo que aparecer como destino vira uma linha nova. Repita até não surgir nenhum conjunto novo (inclusive ∅).
  5. É final no AFD todo conjunto que contém pelo menos um estado final do AFN (aqui, q2).
  6. Se você listou todos os subconjuntos (2³ = 8), marque como inacessível todo conjunto que não aparece como destino saindo de {q0}. Eles são cortados do AFD final.

Tabela de transição do AFN

Passo 1

Preencha para onde cada estado vai com a e com b. A seta → marca o inicial e o * marca o final.

Pode escrever {q1,q2}, q1q2 ou q1, q2. Para vazio use -, vazio ou ∅. Célula em branco conta como não respondida.

Tabela de transição do AFD

Passo 2

Pode fazer de dois jeitos: listar os 8 subconjuntos (incluindo ∅), preencher tudo e marcar os inacessíveis; ou começar por {q0} e só criar linha para os conjuntos que aparecem como destino. Marque também o inicial e os finais.

Escreva os estados como conjuntos: {q0}, {q1,q2}, ∅. A ordem das linhas não importa. A linha do estado vazio (∅) é opcional: com ou sem ela, está certo.

Organizar: renomear para S0, S1, S2…

Com a tabela montada, troque os conjuntos por nomes curtos. S0 é sempre o estado inicial e os marcados como inacessíveis ficam de fora. Os nomes aparecem numa coluna nova, ao lado dos estados, e as colunas a e b passam a usar os nomes S. O botão do olho volta para a tabela original; para editar as transições, use a tabela original.

Conferindo o AFD

Passo 3

Use a sua tabela do AFD para responder. Para testar uma cadeia, comece em {q0} e vá seguindo a tabela símbolo por símbolo.

Diagrama do AFD

Passo 4

Monte o desenho sem desenhar: adicione os estados, arraste para organizar e ligue as transições. Para ligar, escolha o símbolo, clique no estado de origem e depois no de destino (clicar duas vezes no mesmo estado cria um laço).

Escolha o símbolo e clique em um estado para começar uma transição.
